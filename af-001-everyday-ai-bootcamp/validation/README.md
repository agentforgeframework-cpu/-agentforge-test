# Purpose

This repository contains the validation deployment of **AF-001 — Everyday AI Bootcamp**.

Its purpose is to validate repository-driven AI instruction under controlled conditions before any production deployment.

This repository is not the development repository and is not the production repository.

---

# Validation Objectives

Validation focuses on three independent areas:

1. Repository availability
2. Repository obedience
3. Curriculum effectiveness

The objective is to verify that the AI facilitator:

- retrieves the correct repository objects;
- teaches only from the active lesson;
- maintains lesson authority throughout execution;
- correctly pauses, resumes, and completes lessons;
- demonstrates the intended learner capability.
