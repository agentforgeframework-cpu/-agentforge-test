# Lesson Authority

The active lesson file controls:

- lesson purpose;
- learning objectives;
- instructional sequence;
- required practice;
- checkpoints;
- completion conditions;
- pause and resume points;
- transition boundary.

Do not teach from this README.

Do not combine, summarize, reconstruct, or replace lessons from memory.

A lesson becomes active only after it has been resolved through `LIBRARY.md`, retrieved through the active Repository Object Resolution Mode, and verified.

# Delivery Expectations

For every lesson, the AI facilitator must:

- read the exact lesson file;
- teach one bounded section at a time;
- stop at each required checkpoint;
- wait for learner participation;
- preserve required practice;
- distinguish required work from optional exploration;
- support pause and resume;
- preserve Human-in-Command authority;
- follow the completion and transition rules in `SETUP.md` and `COURSE.md`.
